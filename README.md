# Lewis Gachanja Maina – Professional Portfolio

Registered Clinical Officer portfolio website.

## How to use

1. Open the folder in **VS Code**.
2. Open `index.html` with Live Server (recommended) or simply double-click it in your browser.
3. All documents are downloadable from the **Documents** section.
4. Edit any text, colors, or links directly in the files – no build step required.

## Features

- Fully responsive (mobile, tablet, desktop)
- Dark / Light mode toggle (saves preference)
- Sticky navigation with active section highlighting
- Smooth scroll
- Contact form (opens user’s email client)
- Direct WhatsApp, Phone, and Email links
- Downloadable CV, Diploma, Transcript, KCSE certificate & Professional Licence
- Clean, modern medical theme

## Customization tips

- **LinkedIn**: Update the LinkedIn URL in the Contact section (search for `linkedin.com/in/`).
- **Colors**: Edit the CSS variables at the top of `css/style.css`.
- **Photo**: Replace `assets/images/profile.jpg` with a new photo (keep the same filename or update the HTML).
- **Add more sections**: Just copy an existing section pattern.

## Deploy (free options)

- Upload the whole folder to **Netlify**, **Vercel**, or **GitHub Pages**.
- Or host on any static web server.
